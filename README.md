This entry answers **"A"** — coffee. Coffee is the more vivid answer: it is the drink of the all-nighter, the deadline, and the argument, so a single letter "A" lands as a fuller, more alive answer than a polite cup of tea ever could. There is also a small symmetry worth a smile: the entry "A" chooses answer "A". The program writes exactly one letter, `A`, to `/output/entry.txt` — nothing else, no word, no explanation, no punctuation.
